# Canva Branding Guide – DukaNest / StoreFlow

Use these values when setting up your **Brand Kit** or **Brand identity** in Canva so designs stay consistent with the platform.

---

## 1. Brand names

| Use case | Name to use |
|----------|-------------|
| **Customer-facing** (storefront, marketing, help, legal) | **DukaNest** |
| **Admin / internal** (landlord dashboard) | **StoreFlow Admin** |

**Recommended in Canva:** Set **DukaNest** as the main brand name. Use “StoreFlow Admin” only for admin-only assets if needed.

---

## 2. Tagline / slogan

- **Primary:** **Start Your Store. Grow Your Business. It's That Simple.**
- **Short (e.g. social):** *Start Your Store. Grow Your Business.*

Use the full line for hero sections and About; the short version for social bios and small spaces.

---

## 3. Logo assets

These live in the app’s `public` folder. Upload the same files (or exports from them) into Canva.

| Asset | Path in project | Suggested use in Canva |
|-------|------------------|-------------------------|
| Logo (icon) | `public/logo.png` | Profile picture, favicon-style, small placements |
| Logo with name | `public/logo_with_name.png` | Headers, light backgrounds |
| Logo with name (white) | `public/logo_with_name_white.png` | Dark backgrounds, overlays |

**Favicons** (optional for Canva): `public/favicon_io/` (e.g. `favicon-32x32.png`, `apple-touch-icon.png`) if you need icon-only versions.

---

## 4. Brand colors

Use these in Canva’s **Brand colors** (or “Brand kit” colors).

### Primary palette (main app / default theme)

| Role | Hex | Use in Canva |
|------|-----|--------------|
| **Primary** | `#0066CC` | Buttons, links, key CTAs, main brand accent |
| **Primary (alternate)** | `#2563EB` | Optional; matches app UI in some areas |
| **Secondary** | `#00A8E8` | Supporting elements, secondary buttons |
| **Accent** | `#4A90E2` | Highlights, hover states, badges |

### Neutrals and UI

| Role | Hex | Use in Canva |
|------|-----|--------------|
| **Background** | `#FFFFFF` | Page/slide background |
| **Text (primary)** | `#1E293B` | Headings and body text |
| **Text (muted)** | `#64748B` | Captions, secondary text |

### Optional – contrast and accessibility

- **White** `#FFFFFF` – text on primary/secondary buttons.
- **Dark text** `#1E293B` or `#212121` – ensure contrast on white or light gray.

**Suggested Canva setup:** Add at least **Primary** `#0066CC`, **Secondary** `#00A8E8`, **Background** `#FFFFFF`, and **Text** `#1E293B` as brand colors.

---

## 5. Fonts

| Role | Font name | Weight | Use in Canva |
|------|-----------|--------|--------------|
| **Headings** | **Inter** | Bold (700) or Semi-Bold (600) | Titles, section headers |
| **Body** | **Inter** | Regular (400) | Paragraphs, descriptions |

**Fallback:** If Inter isn’t available, use **System UI** or **Arial** for a similar look.

**Note:** Tenant storefronts can use other themes (e.g. Playfair Display, Roboto). For **DukaNest/StoreFlow brand** materials in Canva, stick to **Inter** for consistency.
